## Duplicate check method
1. For every keyed decision, grep of `scratchpad/allkeys.tsv` (5 488 keyed answers, refreshed today) and of `src/samps` with a helper that reports the owning SAMP id for each hit, using core terms and synonyms. Terms and closest hits are in each row above.
2. Each draft's title, stem, updates and keyed answers were written to `scratchpad/g01/draft-<id>.txt` and run through `python3 scratchpad/simcheck.py <file> <id>`. Every printed card was read, not only the scores.
3. `src/samps` was re-grepped at the end of the work for all twelve new stories, because other writers are working in parallel. Nothing new collided.
