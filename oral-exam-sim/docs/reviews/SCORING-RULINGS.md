# Bank-wide scoring rulings

Rules that apply to every SAMP, not only the one where they were first made. A writer must read this file before changing any match phrase, accept item or unacceptable item. A reviewer must FAIL a change that breaks one of these rules unless the writer names the rule and gives a reason.

|---|---|---|---|

## Rulings collected from earlier reviews

A read-only pass over the batch, conformance and sweep reviews, the spec and the briefs collected these. Duplicates are merged. Each row names its sources.

**Conflict for Arjan (A8 against docs/SCORER-NEGATION.md):** A8 comes from SAMP_SPEC section 12. It tells writers to put the negation inside the accept phrase ("avoid X"). The scorer matches such a phrase whenever its words appear anywhere in the line. So a wrong line like "give X, avoid delay" scores it. A8 is how the 313 exposed questions in the second scorer finding were built. Keep following A8 until the scorer decision is made, because removing the negation would stop correct negated answers from scoring at all. Probe every such phrase against a wrong line that orders the thing.
