# Signed-off SAMPs that duplicate each other

For Arjan. This covers only the SAMPs you signed off, s01 to s18.

Both copies in each cluster were signed off. Your attestation covers each text exactly as written.

Nothing here has been changed. No SAMP was edited.

The problem is that a candidate meets the same case twice or more, under different topics. Each duplicate also counts twice toward key-feature coverage, so coverage looks better than it is.

Signed-off SAMPs stay untouched until you decide.

If you approve a rebuild, the rebuilt SAMP gets new text. Your earlier sign-off does not cover that text. It goes back to `reviewed: false` and needs a fresh sign-off from you, like any new SAMP. The kept copy stays signed off as it is.

## How this was found

- A bank-wide sweep compared signed-off SAMPs with each other. A pair counts as a duplicate when both tell the same patient story and key the same teaching point.
- Two adjudicators confirmed every pair. The second was blind to the first.
- Pairs that share a SAMP are grouped into a cluster. That gives 74 clusters holding 181 SAMPs.
- For this document every SAMP in every cluster was read again in full.
- 118 near-miss pairs were judged BORDERLINE. They are listed in the appendix.

## How to read each section

- **Keep** names one copy. The first rule was the priority topic that owns the story. The second rule was the stronger keys and sources.
- **Rebuild** gives a direction for each other copy. It is a new patient story in that SAMP's own topic. It keeps the same key-feature numbers, listed in brackets. It keys a decision that a keyword search of the whole bank (s01 to s53) did not find keyed elsewhere. Close neighbours are named where they exist. A writer should still check the bank before drafting.
- **Lighter option** appears where the cluster is a chain. In a chain some copies were never paired with each other. Rebuilding fewer SAMPs can clear every confirmed pair. The option says which ones.

## Counts

- 74 clusters and 181 SAMPs.
- Keeping one copy per cluster means 107 rebuilds.
- Taking every lighter option instead means 89 rebuilds. That keeps 18 more signed-off SAMPs.
- Where I think a pair is not a full duplicate, the section says so.
